# Entwickler Kontext

Kennt Repo Struktur, möchte Dokuemnte flexible in src oder doc ablegen
benötigt Pfadauswahl oder filebrowser

## us01- fileBrowser für Ablage ort

Als Entwickler möchte ich beim Anlegen eines neuen Dokuemnts einen Filebrowser für das Repository nutzen könen, damit ich das Dokument im gewünschten /src folder ablegen kann

## us02- Template Vorschläge

Als Entwickler möchte ich dass mir beim Anlegen eines Dokuments Templates vorgeschlagen werden, damit ich die Frontmatter Struktur nicht manuell pflegen muss

## us03- MArkdown editor

Als Entwickler möchte ich eine modernen Markdown Editor nutzen können mit Live-Preview, Syntax Highlight, Tabellen, Codeblöcken, damit ich Dokumente komfortable im Tool schreiben kann

## us04- MEtadaten bearbeiten

Als Entwickler möchte ich die Metadaten des Dokuments bearbeiten können

## us05- Speichern/Committen

Als Entwickler möchte ich dass das Dokument nach dem Speichern automatisch ins Repo geschrieben (committed) wird
