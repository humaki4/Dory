# Admin Bereich - zentrale Aufgaben

## US-1: Spaces erstellen

Als Moderator möchte ich neue Spaces erstellen können, damit Dokumente und Projekte organisatorisch zugeordnet werden können

## US-2: Projekte erstellen

Als Moderator möchte ich ein neues Projekt innerhalb eines Spaces erstellen können, damit Repositories und Dokumente logisch gruppiert werden können.

## US-3: Repositories zuordnen:

Als Moderator möchte ich Repositories zu Projekten hinzufügen oder verschieben können, damit die Dokumente automatisch im richtigen Kontext angezeig twerden

## US-4: Doc-Templates erstellen

Als Moderator möchte ich neue Doc-Templates erstellen definieren können (z. B. ADR, ReadME, HowTo, Runbook), damit Nutzer beim Erstellen automatisch die passenden Metadatenfelder und Struktur bekommen
(Frontmatter-template)

## US5: Spaces, Projekt, Repo in Übersicht einbauen

Als Anwender möchte ich eine übersichtliche Darstellung der Spaces, Projekte und Repos, damit ich gezielt Dokumente raussuchen kann

## sUS6: Spaces, Projekte, Repos in Suchen berücksichtigen

Als Anwender möchte ich die Suchen auf bestimmte Bereiche/PRojekte/Repos einschränken können
