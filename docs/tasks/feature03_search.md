# Such und Filter Feature

## 01-Globale Suche starten

Als BA/PO möchte ich in der Weboberfläche eine globale Suche starten, damit ich alle Dokumente unabhängig von Space, Project oder Repo finden kann

## 02-Kontextwahl für die Suche

Als Nutzer möchte ich den Suchbereich auf Spaces, Projekte oder repo einschränken können, damit ich gezielt relevante Ergebnisse finde

## 03-Metadatenbasierte Filter

Als Nutzer möchte ich Suchergebnisse nach Metadaten filtern können:

- Type, Status, domain etc.

## 04- Vorschläge und Autocomplete

Als Nutzer möchte ich dass das Suchfeld beim Tippen Vorschläge aus vorhandenen Tags, Domains Prjekten etc. liefert, damit ich schneller passende Suchergebnisse verwenden kann

## 05-Suchergabnis Darstellung mit Kontext

Als Nutzer möchte ich dass Suchergebnisse in einer übersichtlichen Ansicht angezeigt werden inkl.

- Pfad zum Ordner im Repo
- Doc-Typ und STatus
- Domain/Tags etc
- kurzer Snippet/Preview
- Verknüpfte Doks
